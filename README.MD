### `base.py` — Базовая архитектура
Содержит абстрактные классы, от которых строится вся игра:
- `base.py` — хранит 6 характеристик, список заклинаний и текущую ману. Объявляет абстрактные методы `calculate_max_health`, `calculate_damage`, `calculate_defense`, а также методы `add_spell` и `cast_spell` для управления магией.
- `Spell` — базовый класс для заклинаний. Хранит название, урон и стоимость маны. Требует реализации метода `cast()`.

### `character.py` — Игровой персонаж
Класс `Character`, наследующий `base.py`. Логика расчёта параметров завязана на атрибуте `character_class`:
- Поддерживаемые классы: `'warrior'`, `'mage'`, `'hunter'`.
- При создании автоматически рассчитываются `max_health`, `damage`, `defense` и `max_mana` по формулам из методички.
- Текущая мана при создании равна максимальной.
- При некорректном значении класса выбрасывает `ValueError`.

### `monster.py` — Монстры
Класс `Monster`, наследующий `base.py`. Реализует упрощённые формулы для противников:
- HP: `телосложение * 8 + сила // 3`
- Урон: `сила * 2 + телосложение // 5`
- Защита: `телосложение * 1.2 + сила // 5`

### `spall.py` — Заклинания
Конкретные реализации магии (наследники `Spell`):
- `Fireball` (урон 35, стоимость 15)
- `IceLance` (урон 25, стоимость 10)
- `LightningBolt` (урон 40, стоимость 20)
- Метод `cast()` возвращает базовый урон (пока без доп. логики).
